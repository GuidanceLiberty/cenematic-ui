## Tech Stack
- Framework: React / Vite / Shadcn
- Animations: GSAP + ScrollTrigger + Framer Motion
- Styling: Tailwind CSS
- Deployment: Vercel

## Creative Replacement for 3D
I replaced the original 3D experience with:
- A cinematic looping video background combined with layered parallax text and scroll-driven transitions to maintain immersion.

## Key Features
- Scroll-synchronized animations
- Cinematic typography & layout
- Optimized performance using requestAnimationFrame / GSAP timelines
- Responsive layout

## AI Tool Usage
I used AI tools (ChatGPT & Gemini) for:
- Brainstorming animation ideas
- Debugging GSAP timelines
- Structuring components

## Reflection
If given more time, I would:
- Improve mobile scroll performance for smoother touch scrolling.
- Add subtle sound design to enhance the cinematic experience.
- Enhance accessibility, including reduced motion support and better ARIA labeling.
- Explore more advanced scroll-driven 3D-like animations to more closely match the original site's immersive feel.
- Experiment with additional creative ideas to make the UI more interactive and engaging.
